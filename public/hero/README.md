# Optional local covers

Add your own artwork here: `home.jpg`, `naruto.jpg`, `onepiece.jpg`, `bleach.jpg`.
The existing CSS gradients remain visible when a cover is absent or fails to load.
No website image search or downloader runs. Covers are decorative; headings stay as text.
Use owned, licensed or CC0 backgrounds. Check each asset's actual permissions before publishing.
Character images are separate and continue through `CharacterAvatar`.
